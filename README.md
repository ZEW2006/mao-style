# mao-style —— 毛式文风

一个 DeepSeek Harness（DSH）技能：用《反对党八股》的方法审文，用《改造我们的学习》的标准改文。按八大罪状逐条查，按实事求是立标准，把文章改得实在、有针对性。

## 何时用

- 要求把文章改得「实在」「不空」「有针对性」
- 审阅讲话稿、汇报、评论、宣传稿
- 提到「党八股」「实事求是」「有的放矢」

## 安装

把本仓库克隆（或下载复制）到 DSH 技能库，目录名保持 `mao-style`：

```bash
git clone https://github.com/ZEW2006/mao-style ~/.dsh/skills/mao-style
```

Windows 上技能库在 `%USERPROFILE%\.dsh\skills\`。装完新开会话即生效。

## 用法

直接说「用 mao-style 审这篇稿」「把这篇改得实在一点」，或在文稿任务里提到党八股、实事求是，技能会自动介入。流程：定对象 → 标段落 → 过八条 → 删三成 → 交付改后稿与改动说明。

## 包含内容

- **八条罪状，八条判据**（《反对党八股》，1942-02-08）
- **正面标准**（《改造我们的学习》，1941-05-19）
- **三条补充**（《在延安文艺座谈会上的讲话》，1942-05-02）
- 五步操作步骤、八项检查清单、三条使用边界
